## 二、今日事模块 (pages/note/)

### 2.1 功能概述

「今日事」是用户的事程管理中心，支持创建、编辑、删除日程，并提供日历视图和提醒功能。

### 2.2 页面列表

| 页面 | 文件 | 功能 |
|------|------|------|
| 事程列表 | list.vue | 日历+列表展示事程 |
| 新增事程 | add.nvue | 创建/编辑事程 |
| 事程详情 | detail.vue | 查看事程详情 |

### 2.3 核心功能

#### 2.3.1 事程列表 (list.vue)

**功能点：**
- 日历组件展示，标记有事的日期
- 按日期筛选事程列表
- 事程状态管理（待完成/已完成）
- 下拉刷新、上拉加载

**数据流：**
```
页面加载 → 获取日历事程数量 (note_num) → 渲染日历标记
选择日期 → 获取事程列表 (note_list) → 渲染列表
```

#### 2.3.2 新增/编辑事程 (add.nvue)

**表单字段：**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 事程标题 |
| content | string | 否 | 事程内容 |
| start_time | datetime | 是 | 开始时间 |
| end_time | datetime | 否 | 结束时间 |
| is_all_day | boolean | 否 | 是否全天 |
| remind_type | number | 否 | 提醒类型 |
| push_notice | boolean | 否 | 是否推送提醒（VIP 功能） |

**提醒类型：**
- 0: 不提醒
- 1: 准时提醒
- 2: 提前5分钟
- 3: 提前15分钟
- 4: 提前30分钟
- 5: 提前1小时
- 6: 提前1天

### 2.4 相关 API

| API | 方法 | 说明 |
|-----|------|------|
| note_list | POST | 获取事程列表 |
| note_add | POST | 新增事程 |
| note_editor_get | POST | 获取事程详情（编辑用） |
| note_editor | POST | 编辑事程 |
| note_del | POST | 删除事程 |
| note_state_set | POST | 修改事程状态 |
| note_num | POST | 获取日历事程数量 |

## 三、微逛模块 (pages/weiguang/)

### 3.1 功能概述

「微逛」是信息聚合浏览模块，用户可以浏览招标采购、工作招聘、周边友圈、项目信息、会议信息、通知公告等多种类型的内容。

### 3.2 页面列表

| 页面 | 文件 | 功能 |
|------|------|------|
| 内容列表 | list.nvue | 多类型内容聚合展示 |
| 内容详情 | detail.nvue | 内容详情、评论、点赞 |

### 3.3 内容类型

| ID | 名称 | 说明 |
|----|------|------|
| bid | 招标采购 | 招标信息 |
| job | 工作招聘 | 招聘信息 |
| publish | 周边友圈 | 用户发布内容 |
| project | 项目信息 | 项目相关 |
| meeting | 会议信息 | 会议/活动 |
| notice | 通知公告 | 公告通知 |

### 3.4 核心功能

#### 3.4.1 内容列表 (list.nvue)

**功能点：**
- 多类型内容聚合展示
- 筛选功能（时间、类型、来源）
- 排序功能（默认/最新发布）
- 频道切换
- 下拉刷新、上拉加载

**筛选维度：**
- **时间筛选**：不限/近1天/近3天/近1周/近1月/近3月/近半年/近1年
- **类型筛选**：会议信息/项目信息/通知公告/人事招聘/招标采购/发布
- **来源筛选**：行业协会/企业/个体/教育机构/政府/军队/其他
- **排序字段**：标题/单位/时间/地址/阅读量/点赞量
- **排序方式**：默认排序/最新发布

#### 3.4.2 内容详情 (detail.nvue)

**功能点：**
- 内容详情展示（富文本）
- 点赞功能
- 评论功能
- 相关内容推荐
- 分享功能
- 来源链接（VIP 功能）

### 3.5 相关 API

| API | 方法 | 说明 |
|-----|------|------|
| get_weiguang_list | POST | 获取内容列表 |
| get_note_data_detail | POST | 获取内容详情 |
| get_data_detail | POST | 获取补充信息 |
| get_commnet_detail | POST | 获取评论列表 |
| set_like_num | POST | 点赞 |
| set_comment_msg | POST | 发表评论 |
| set_read_num | POST | 增加阅读量 |
| set_share_click_num | POST | 增加分享点击 |
| change_similar | POST | 获取相关内容 |
| get_columns | POST | 获取频道列表 |
| save_columns | POST | 保存频道设置 |

## 四、订阅模块 (pages/order/)

### 4.1 功能概述

「订阅」模块允许用户设置关键词订阅，系统会根据关键词推送相关信息。

### 4.2 页面列表

| 页面 | 文件 | 功能 |
|------|------|------|
| 订阅首页 | index.nvue | 订阅列表管理 |
| 新增订阅 | add.nvue | 创建订阅 |
| 编辑订阅 | editAdd.vue | 编辑订阅 |
| 订阅列表 | list.vue | 订阅历史 |
| 扩增 | kuozeng.vue | 扩增订阅 |

### 4.3 订阅字段

| 字段 | 类型 | 说明 |
|------|------|------|
| keyword | string | 订阅关键词 |
| type | array | 订阅类型（多选） |
| source | array | 来源类型（多选） |
| push_time | string | 推送时间 |
| push_notice | boolean | 是否推送（VIP） |

### 4.4 订阅流程

```
创建订阅 → 选择关键词 → 选择类型 → 选择来源 → 设置推送时间 → 保存
    ↓
系统匹配内容 → 按时推送 → 用户查看
```

### 4.5 相关 API

| API | 方法 | 说明 |
|-----|------|------|
| get_order_list | POST | 获取订阅列表 |

| set_order | POST | 创建订阅 |
| update_order | POST | 更新订阅 |
| delete_order | POST | 删除订阅 |

| get_push_num | POST | 获取推送数量 |
