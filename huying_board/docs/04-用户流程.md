# 用户流程

## 一、用户认证流程

### 1.1 登录流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  打开登录页  │────▶│  输入凭证   │────▶│  点击登录   │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                    ┌─────────────┐     ┌──────▼──────┐
                    │  存储Token  │◀────│  调用API    │
                    └──────┬──────┘     └─────────────┘
                           │
                    ┌──────▼──────┐
                    │  获取权限   │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │  跳转首页   │
                    └─────────────┘
```

### 1.2 登录方式

**方式一：用户名+密码**
```
用户名 + 密码 → login API → 获取 Token → 存储
```

**方式二：手机号+验证码**
```
手机号 → 获取验证码 → 输入验证码 → tel_login API → 获取 Token
```

### 1.3 Token 自动刷新

```
请求 API
    │
    ▼
401/403 错误？
    │
    ├── 是 ──▶ 使用缓存的 credential 重新登录
    │              │
    │              ▼
    │         登录成功？
    │              │
    │              ├── 是 ──▶ 重试原请求
    │              │
    │              └── 否 ──▶ 跳转登录页
    │
    └── 否 ──▶ 正常处理响应
```

## 三、微逛浏览流程

### 3.1 列表浏览

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  进入微逛   │────▶│  加载列表   │────▶│  选择筛选   │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                    ┌─────────────┐     ┌──────▼──────┐
                    │  渲染结果   │◀────│  重新请求   │
                    └─────────────┘     └─────────────┘
```

### 3.2 查看详情

```
点击内容卡片
    │
    ▼
跳转详情页
    │
    ├──▶ 获取内容详情 (get_note_data_detail)
    │
    ├──▶ 获取评论列表 (get_commnet_detail)
    │
    ├──▶ 获取相关内容 (change_similar)
    │
    ▼
渲染详情页
    │
    ├──▶ 增加阅读量 (set_read_num)
    │
    └──▶ 用户交互（点赞/评论/分享）
```

### 3.3 互动操作

**点赞流程：**
```
点击点赞 → 调用 set_like_num → 更新 UI
```

**评论流程：**
```
输入评论 → 提交 → 调用 set_comment_msg → 刷新评论列表
```

**分享流程：**
```
点击分享 → 调用微信 JSSDK → 分享成功 → 调用 set_share_click_num
```
