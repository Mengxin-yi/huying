## 二、请求层架构

### 2.1 请求封装 (request.js)

```
┌─────────────────────────────────────────────────────┐
│                   request.js                         │
├─────────────────────────────────────────────────────┤
│  queryWithToken(query)                              │
│  ├── 自动注入 token                                 │
│  └── 返回带 token 的 query                          │
├─────────────────────────────────────────────────────┤
│  queryWithSearch(query)                             │
│  ├── 注入分页参数                                   │
│  └── 返回带分页的 query                             │
├─────────────────────────────────────────────────────┤
│  postReqeustSys(query, api)     → /bpi/             │
│  postReqeust(query, api)        → /cpi/             │
│  postReqeust3rd(query, url)     → 第三方 API        │
│  wcqPostReqeust(query, api)     → /wpi/             │
│  uploadReqeustSys(query, api)   → /bpi/ 上传        │
│  uploadReqeust(query, api)      → /cpi/ 上传        │
└─────────────────────────────────────────────────────┘
```

### 2.2 API 响应处理

```javascript
// /bpi/ 响应格式
{
  status: 200,
  message: "success",
  items: [],
  total: 100
}

// /cpi/ 响应格式
{
  status_code: 200,
  message: "success",
  data: {},
  items: []
}
```

### 2.3 Token 自动刷新机制

```javascript
// 请求拦截
request.interceptor = (config) => {
  config.header['app-name'] = 'huying';
  config.header['token'] = getToken();
  return config;
}

// 响应拦截
response.interceptor = (response) => {
  if (response.statusCode === 401 || response.statusCode === 403) {
    // 自动重试登录
    const credential = uni.getStorageSync('credential');
    if (credential) {
      return login(credential).then(() => {
        return retryRequest(config);
      });
    }
    // 跳转登录页
    uni.redirectTo({ url: '/pages/prefer/user/signin' });
  }
  return response;
}
```
